# MVP Execution Plan

## Goal
Deliver a playable backend foundation for an original BR game in iterative steps.

## Milestone 1 (this commit)
- Project scaffold
- Health check
- Lobby join
- Queue enqueue
- Wallet transaction-intent endpoints (mock)

## Milestone 2
- Authoritative match session service
- Simple bot-fill logic
- Loadout/profile service

## Milestone 3
- Persistence (PostgreSQL)
- Redis queue
- Auth + anti-abuse middleware

## Milestone 4
- Payment gateway integration (Razorpay/Stripe)
- KYC & withdrawal review workflows
- Audit logging
